# GearPower v1.2.8

开机自启动与首次功能引导。

## 新增

### 开机自动启动

- 设置 → 启动 → 「开机自动启动」开关
- **默认关闭**
- 开启后登录 Windows 会正常显示：
  - 主窗口
  - 系统托盘
  - 任务栏电量条
- 使用当前用户注册表，不需要管理员：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
GearPower = "...\GearPower.exe"
```

- 不创建计划任务，不自动提权
- 便携版移动位置后，下次启动会自动修正路径
- 关闭开关会删除启动项

### 首次功能引导

第一次打开时显示 4 页引导：

1. 欢迎与自动扫描
2. 电量卡片与历史设备
3. 托盘与任务栏电量条
4. 重命名、主题和设备适配

- 支持上一步/下一步/跳过
- 关闭后不再自动显示
- 设置页「重新查看功能引导」可再次打开
- 已有历史或缓存数据的升级用户不会看到首次引导，避免打断
