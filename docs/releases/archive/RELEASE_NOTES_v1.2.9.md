# GearPower v1.2.9

新拟物菜单键帽与滑动开关。

## 修复

- 修复新拟物阴影设置只读对象导致的启动崩溃
- 菜单键帽与开关的阴影改为可写实例，避免窗口创建阶段异常

## 新增

- 顶部「电量 / 设备清单 / 设备适配 / 设置」改为新拟物键帽
- 默认凸起，带柔和外阴影
- 鼠标悬停时轻微上浮
- 按下时外阴影切换为内阴影，并下沉 2px
- 松开使用回弹缓动
- 当前菜单项保持按下状态，并亮起强调色指示灯
- 指示灯使用当前强调色和柔光效果
- 所有开关改为新拟物滑动开关：滑块带吸附和回弹缓动，开启后指示灯常亮
- 浅色主题改为参考图的暖米白 `#F2E8E0`、同色卡片和柔和双向阴影
- 卡片、汇总栏和设置面板去除生硬描边，改用暖灰阴影塑形
- 设置页的主题、强调色、刷新和关闭选项改为新拟物按键
- 当前项与开启状态统一使用钴蓝 `#2F4BD0` 指示灯

## 交互细节

```text
静止      凸起
悬停      -2px 上浮，阴影加深
按下      +2px 下沉，内阴影
松开      BackEase 回弹
当前项    +2px 保持按下，LED 常亮
```

切换菜单时，上一项回弹抬起，新项保持按下。
