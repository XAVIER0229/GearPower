# GearPower v1.2.7

设备名称自定义。

## 新增

- 电量卡片右上角新增铅笔按钮，可重命名设备
- 右键电量卡片也有「重命名设备…」菜单
- 支持「恢复默认」，随时撤销自定义名称
- 历史设备卡片同样可以重命名
- 删除历史卡片时会一并清理该设备的自定义名称

## 命名规则

- 只修改显示名称
- 不修改 VID/PID、读取协议、配对或设备设置
- 重命名同步到：
  - 电量卡片
  - 系统托盘图标提示
  - 悬停电量卡片
  - 任务栏电量条
- 名称按设备容器 ID 保存，重新连接后仍然生效

存储位置：

```text
%LOCALAPPDATA%\GearPower\device-names.tsv
```
