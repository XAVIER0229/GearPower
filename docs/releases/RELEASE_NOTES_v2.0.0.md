# GearPower v2.0.0

以 `GearPower-Qiju/release3` 的 Qiju Soft UI 重制版作为本次更新内容。

## 主要变化

- 全新 250px 固定侧栏：品牌、WORKSPACE 导航、设备概览卡
- 页头：kicker、24px 标题、说明、蓝牙开关、重新扫描
- KPI 四卡：已连接、平均电量、低电量（≤20%）、历史设备
- 双列设备卡，176px 高，86px 环形电量
- 设备清单、设备适配、设置页全部改为 Qiju 双列软卡片
- 固定单一暖米白主题，移除浅色 / 深色 / 强调色切换
- 关闭确认、重命名、首次引导、提权弹窗统一 Qiju 样式
