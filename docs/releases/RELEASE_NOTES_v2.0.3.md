# GearPower v2.0.3

侧栏设备概览卡与信息重复问题的修正版。

## 修正

- 设备概览卡改为「中间平底、四周凹陷」：
  - 顶部与左侧内凹暖灰
  - 底部与右侧内凹白色高光
  - 中间保持与页面一致的平底色
- 新增平均电量钴蓝进度条
- 调整卡片内层级：标题 / 在线数 / 平均与低电 / 进度 / 历史设备
- 移除卡片内「本地读取 · 不联网」
  - 只在底部状态栏保留一次
- 顶部摘要不再显示「已发现 N 台设备」
  - 改为「扫描完成 · 最低 X%」
  - 设备数量只在侧栏显示一次
- 设备卡片重新渲染后自动滚回顶部
- 暗色主题关闭所有投影，只保留平面边框
- 切换主题时同步刷新导航、分段按钮、设置选项和状态颜色
- 「关于」版本号读取程序集，显示 GearPower 2.0.3

## 保留

- 暗色主题
- 工作台 / 系统导航分组
- 设备清单默认折叠
- PR #15 的历史设备去重、经典蓝牙离线过滤、Apple 05AC:0255 实验性电量
- Qiju 风格历史合并弹窗
- 全部扫描、清单、适配、设置、托盘、任务栏、开机启动功能
