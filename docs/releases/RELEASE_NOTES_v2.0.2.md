# GearPower v2.0.2

Qiju Soft UI 的第二轮修正版。

## 界面修复

- 「关于」版本号改为读取程序集版本，显示 `GearPower 2.0.2`
- 设备清单默认折叠全部设备组，按需展开
- 新增暗色主题开关，主题持久化到注册表
- 暗色主题覆盖背景、卡片、文字、按钮、开关、输入框、弹窗与标题栏
- 侧栏设备概览卡改为默认凹陷
- 侧栏导航按「工作台 / 系统」分组
- 底部状态提示与主内容增加间距

## 保留

- PR #15 的历史设备去重、经典蓝牙离线过滤、Apple 05AC:0255 实验性电量
- Qiju 风格历史合并弹窗
- 全部扫描、清单、适配、设置、托盘、任务栏、开机启动功能
