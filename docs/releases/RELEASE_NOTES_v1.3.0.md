# GearPower v1.3.0

整套 UI 重做：左侧导航 + 右侧内容的 Soft UI 工作台。

## 新布局

- 参考 `neumorph-console/docs/Qiju-SoftUI-UI-Spec-v1.0.docx/.pdf`
- 参考 `neumorph-console/docs/design-tokens.json`
- 采用 250px 侧栏、24px 页面外边距、30px 侧栏/主区间距、24px 卡片圆角、16px 控件圆角
- 采用 tokens 的卡片/按钮/凹陷阴影参数与 225°/45° 光影方向
- 侧栏改为带 1px 白色表面边和 sh-card 阴影的独立卡片
- 新增桌面 KPI 行：已连接 / 平均电量 / 低电量 / 历史设备
- 保留设备卡片、清单、适配、设置、托盘、开机启动、首次引导等全部功能
- 导航未选中项保持平整，当前项为内凹胶囊 + 钴蓝指示灯
- 右侧顶部为页面标题和说明，下面才是扫描状态
- 电量卡片按内容区宽度自适应
- 侧栏底部集中蓝牙电量开关和重新扫描

## 视觉

- 暖米白背景 `#F2E8E0`
- 卡片、导航、设置面板同底色，只靠阴影成形
- 左上高光、右下暖灰暗影
- 卡片圆角 24px，导航键帽圆角 16px
- 去掉生硬灰边框
- 当前导航项保持按下，钴蓝 `#2F4BD0` 文字和指示灯
- 设置页的主题、强调色、刷新、关闭选项改为新拟物按键

## 开关

- 内凹轨道、白色凸起滑块
- 滑动 240ms，`BackEase` 吸附回弹
- 开启时滑块和指示灯变钴蓝

## 修复

- 修复 WPF 冻结阴影对象导致的启动崩溃

## 验证

- 自检：81 项通过
- 侧栏布局、当前导航项、设置选项和开关均在浅色主题下检查
